# AI Readiness Workforce Transition Index
## Overview
AI Readiness Workforce Transition Index is an analytical frontend platform
designed to visualize workforce transformation trends under AI adoption.
The project explores:
- workforce transition readiness
- sector-level transformation indicators
- AI adoption impact
- labor market restructuring
- policy recommendation visualization
## Features
- Interactive workforce dashboard
- Sector readiness visualization
- Policy recommendation sections
- Responsive UI architecture
- TailwindCSS-based frontend system
- Vercel deployment workflow
## Tech Stack
- React
- Vite
- TailwindCSS
- GitHub
- Vercel
